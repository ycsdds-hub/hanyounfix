# 한영 오타 자동 교정 (hanyoung-fix)

한/영 전환을 잘못한 채로 입력한 단어를 바로 고쳐 줍니다.

- **Chrome 확장** (`extension/`): 웹페이지 입력창에서 동작
- **Windows 앱** (`windows/`): 메모장, 카카오톡, 오피스 등 모든 프로그램에서 동작하고, 한/영 상태까지 바꿔 줍니다

| 이렇게 쳤을 때 | 이렇게 고쳐요 |
| --- | --- |
| `dkssudgktpdy` | `안녕하세요` |
| `ㅗ디ㅣㅐ 재기ㅇ` | `hello world` |
| `hello`, `ㅋㅋㅋ`, `안녕` | 그대로 둡니다 |

## Chrome 확장 설치 (개발자 모드)

1. 이 저장소를 내려받습니다. (`git clone` 또는 **Code → Download ZIP** 후 압축 풀기)
2. Chrome 주소창에 `chrome://extensions` 를 엽니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다** 를 누르고 `extension` 폴더를 선택합니다.

Edge, Whale, Brave 같은 Chromium 기반 브라우저에서도 같은 방법으로 설치할 수 있어요.

## 동작 방식

- **띄어쓰기나 문장부호**를 칠 때 바로 앞 단어를 검사합니다.
- 영어 모드로 한글을 길게 치고 있으면 **띄어쓰기 전에도 6글자부터** 미리 고칩니다. 긴 영어 단어의 앞부분일 수 있으면(예: `abando…`) 끝까지 기다립니다. (설정에서 변경 가능)
- **Enter**를 칠 때도 마지막 단어를 고칩니다. (영어 모드로 잘못 친 경우만, 아래 한계 참고)
- 판단 기준
  - 영어 사전(약 11만 단어)에 없고, 한글로 바꿨을 때 온전한 글자로 조합되면 → 한글로
  - 한글로 쳤는데 낱자(ㅗ, ㅣ 등)가 섞여 있고 영어로 바꾸면 사전에 있는 단어면 → 영어로
  - 온전한 한글 글자로만 되어 있으면 흔한 영어 단어(4글자 이상)일 때만 영어로 바꾸고, `모드`·`재가`처럼 실제 쓰는 한글 단어는 그대로 둡니다
  - `ㅋㅋㅋ`, `ㅠㅠ`, `ㅇㅇ` 같은 표현, 대문자가 섞인 영어(`Seoul`, `iPhone`), 숫자/@/#/URL에 붙은 단어는 건드리지 않습니다.
- 비밀번호, 이메일, URL 입력칸과 코드 편집기(Monaco, CodeMirror, Ace)는 검사하지 않습니다.

## 사용법

- 고친 직후 **Ctrl+Z**(맥은 Cmd+Z)로 되돌리면 원래대로 돌아가고, 그 단어는 앞으로 고치지 않습니다.
- **다시 쓰면 그대로 둡니다:** 고친 글자를 지우고 1분 안에 그 자리에 똑같이 다시 쓰면 일부러 쓴 것으로 보고 그대로 둡니다. 그 단어는 **같은 탭에서 10분**(쓸 때마다 연장), **다른 탭에서 1분** 동안 계속 그대로 두고, 그 뒤에는 다시 고칩니다. 영구히 고치지 않으려면 교정 직후 Ctrl+Z.
- **문맥 교정:** `해 새 ㅓㅐㅠ` 처럼 짧은 단어 뒤의 단어가 고쳐지면 앞 단어도 함께 `go to job` 으로 바꿉니다. (Windows 앱과 같은 규칙)
- 툴바 아이콘을 누르면 설정 창이 열립니다.
  - 자동 교정 켜기/끄기
  - 지금 보고 있는 사이트에서만 끄기
  - 교정 알림 표시 여부
  - 띄어쓰기 전 검사 글자 수
  - 고치지 않을 단어 목록 (이름, 약어, 아이디 등)
- 단축키 **Alt+Shift+H**로 켜고 끌 수 있습니다. `chrome://extensions/shortcuts` 에서 바꿀 수 있어요.

## Windows 앱

모든 프로그램에서 동작하며, 확장과 달리 **한/영 상태도 바꿔 줍니다.** 잘못 친 글자를 지우고, 한/영을 바꾼 뒤, 같은 키를 다시 눌러 줍니다.

### 설치

1. GitHub 저장소의 **Actions** 탭 → 가장 최근 성공한 실행 → **HanYoungFix-windows** 를 내려받아 압축을 풉니다.
   (또는 `windows\build.bat` 을 실행해 직접 만들 수 있어요. Python 3.10 이상 필요)
2. `HanYoungFix.exe` 를 실행합니다. 서명되지 않은 프로그램이라 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요.
3. 작업 표시줄 오른쪽에 아이콘이 생깁니다. 아이콘을 두 번 누르면 설정 창이 열립니다.

소스로 바로 실행하려면: `pip install -r windows/requirements.txt` 후 `pythonw windows/main.py`

### 사용법

- **처음 쓰는 프로그램에서는 한/영 키를 한 번 눌러 주세요.** 그 프로그램이 한/영 상태를 제대로 알려 주는지 확인한 뒤부터 교정합니다. (한 번 확인하면 기억해요.) 상태를 잘못 알려 주는 프로그램에서 엉뚱한 글자를 지우지 않기 위한 안전장치예요.
- 교정 직후 **Ctrl+Z** → 원래대로 되돌리고 그 단어는 앞으로 고치지 않습니다.
- **다시 쓰면 그대로 둡니다:** 교정된 단어를 백스페이스로 지우고 1분 안에 그 자리에 원래 모드로 똑같이 다시 치면, 일부러 쓴 것으로 보고 그대로 둡니다. 그 단어는 **같은 창에서 10분**(쓸 때마다 연장), **다른 창에서 1분** 동안 계속 그대로 두고, 그 뒤에는 다시 고쳐요. 지우지 않고 같은 실수를 또 하면 바로 고칩니다. (영구히 고치지 않으려면 교정 직후 Ctrl+Z)
- **문맥 교정:** 2글자 이하처럼 혼자서는 판단하기 어려운 단어는 건너뛰지만, 바로 뒤 단어가 같은 방향으로 교정되면 함께 고칩니다. 한글 모드로 `go to job` → `해 새 ㅓㅐㅠ` 를 치면 `go to job` 으로 한꺼번에 바뀝니다. (`해 새` 만 따로 치면 그대로)
- **Ctrl+Alt+H** 로 켜고 끕니다.
- 설정: 검사 글자 수(기본 6), 알림, 윈도우 시작 시 자동 실행, 교정하지 않을 프로그램, 고치지 않을 단어
- **chrome.exe 는 기본으로 제외**되어 있습니다. Chrome 확장과 앱이 동시에 같은 글자를 고치면 글자가 지워질 수 있기 때문이에요. 확장을 쓰지 않는다면 설정에서 지워도 됩니다.
- 비밀번호 입력칸(일반 Windows 입력칸)에서는 동작하지 않습니다.

### 한계

- 관리자 권한으로 실행된 프로그램에는 키를 보낼 수 없습니다. 그런 프로그램에서도 쓰려면 앱도 관리자 권한으로 실행하세요.
- 일부 프로그램(UWP 앱, 일부 게임 등)은 한/영 상태를 알려 주지 않아 교정하지 않습니다. 설정 창의 "지금 앞에 있는 프로그램"에서 상태를 확인할 수 있어요.
- 키보드 입력을 감시하는 프로그램이라 백신이 경고할 수 있습니다. 소스는 모두 이 저장소에 있습니다.

## Chrome 확장의 한계

- **브라우저 확장은 운영체제의 한/영 상태를 바꿀 수 없습니다.** 단어는 고쳐 주지만 입력기는 여전히 잘못된 모드이므로, 알림이 뜨면 한/영 키를 눌러 주세요. (바꾸지 않아도 이후 단어들이 계속 교정되긴 합니다.)
- 한글 모드로 영어를 치다 **바로 Enter**를 누르면 마지막 글자가 아직 조합 중이라 고치지 못합니다. 띄어쓰기를 한 번 친 뒤 Enter를 누르면 고쳐집니다.
- Google Docs처럼 자체 방식으로 글자를 그리는 편집기에서는 동작하지 않습니다.
- 사전에 없는 영어(신조어, 고유명사)가 한글 글자로 딱 맞게 조합되면 한글로 바뀔 수 있어요. Ctrl+Z로 되돌리면 다음부터는 그대로 둡니다.
- 브라우저 밖(메모장, 카카오톡 등)에서도 쓰려면 아래 Windows 앱을 사용하세요.

## 개발

```bash
npm install           # 단어 목록 생성용 패키지 설치
npm test              # 변환/판단 로직 테스트
python -m unittest discover -s windows/tests   # Windows 앱 로직 테스트
npm run build:words   # extension/words.txt 다시 만들기
```

```
extension/
  manifest.json   Manifest V3 설정
  hangul.js       두벌식 한영 변환 + 오타 판단 (테스트와 공유)
  content.js      입력창 감시와 교정
  background.js   영어 사전 조회, 단축키, 배지
  popup.*         설정 창
  words.txt       영어 단어 목록 (SCOWL)
  common.txt      흔한 영어 단어 (한글→영어 판단용)
windows/
  main.py         Windows 앱 시작점
  hanyoung/core.py     변환·판단 (hangul.js와 같은 규칙)
  hanyoung/engine.py   키 입력 처리와 교정 (OS 무관, 가짜 IME로 테스트)
  hanyoung/win32.py    키보드 후킹, IME 상태, 키 보내기
  hanyoung/ui.py       트레이 아이콘, 설정 창, 알림
  build.bat       exe 만들기
scripts/          단어 목록 생성 스크립트
test/             node:test 테스트, cases.json(확장과 Windows 앱 공통 사례)
```

## Chrome 웹 스토어에 올리려면

`extension` 폴더의 내용을 zip으로 묶어 [Chrome 웹 스토어 개발자 대시보드](https://chrome.google.com/webstore/devconsole)에 올리면 됩니다. GitHub에 올리면 Actions가 테스트 후 같은 zip을 자동으로 만들어 줍니다.
