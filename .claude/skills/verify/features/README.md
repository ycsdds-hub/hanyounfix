# HanYoungFix Windows 앱 검증 지도

Windows 앱의 사용자 기능을 확인하는 레시피 모음. 몰기 전에 이 목록을 읽고 해당 기능 파일을 따른다.

## 기본 전제

- `launch.py`로 띄운 검증 앱만 몬다. 사용자 앱(`HanYoungFix.exe`, 47321)이나 `%APPDATA%\HanYoungFix`는 건드리지 않는다.
- 설정은 빈 상태에서 시작한다 (신뢰한 프로그램 없음, 교정 켜짐, 띄어쓰기 전 검사 6글자).
- 키보드 배열이 한국어여야 하고 `doctor.py`가 `OK`여야 한다.
- drive 전에 사용자에게 자동 입력을 예고한다.

## 몰기 규칙

- 입력은 `drive.py`가 만든 Tk 창(`hanyoung verify`, 프로그램 이름 `python.exe`)에만 보낸다. 사용자의 메모장 등 다른 창에 치지 않는다.
- 키는 영문 소문자와 띄어쓰기. 한글은 두벌식 자판 위치의 영문 키로 친다 (`dkssud` = 안녕).
- journey마다 창을 비우고 한/영을 시작 상태로 맞춘 뒤 친다.

## 증명과 건너뜀 보고

- 결과 글자 + 화면 변화(trace) + `recent.json` 기록을 같이 본다.
- 교정 안 해야 하는 사례는 기록이 없어야 한다.
- 이 스킬로 못 모는 경로(트레이 메뉴, 설정 창, 실제 키보드 구분)는 "확인 안 됨"으로 보고하고 다른 경로로 대신 증명했다고 하지 않는다.

## 기능 파일 형식

H1 제목과 한 문단 설명 뒤에 H2 네 개: `Sub-features`, `How to get to it (user POV)`, `Driving it with drive.py`, `Gotchas`.

## 기능

- [처음 쓰는 프로그램 신뢰](./trust.md) — 한/영 키를 한 번 눌러야 그 프로그램에서 고치기 시작.
- [오타 교정](./typo-correction.md) — 영어 모드로 친 한글, 한글 모드로 친 영어, 진짜 영어는 그대로.
- [문맥 교정](./context.md) — 짧은 앞 단어도 같이 영어로.
- [최근 교정 기록](./history.md) — 고친 단어 20개를 기록하고 아이콘 메뉴에서 보기.

## 아직 지도에 없는 기능 (드라이버 없음)

- 트레이 아이콘 메뉴: 켜기/끄기, 자동 실행, 설정 창, 종료 (`app/tests/smoke_windows.py`가 일부를 모의로 확인)
- Ctrl+Z 되돌리기 후 그 단어 학습, 지우고 다시 쓰면 그대로 두기
- 비밀번호 칸·제외 앱 건너뛰기, Chrome 주소창
